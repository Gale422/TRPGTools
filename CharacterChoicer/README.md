# 🎲 キャラクター選択ツール

ココフォリア用のchoiceコマンドを簡単に作成できるツールです。キャラクター名やエネミー名を保存・管理し、選択したものに対してchoiceコマンドの文字列を自動生成します。

## 🌟 機能概要

このツールは、ココフォリアで使用する`choice`コマンドを簡単に作成するためのWebアプリケーションです。

### 主な特徴

- ✅ **簡単なコマンド生成**: チェックボックスで選択するだけでchoiceコマンドを作成
- 💾 **キャラクター名の保存**: よく使うキャラクター名をブラウザに保存して再利用可能
- 📁 **グループ分類機能**: キャラクターを分類して整理できる
- 🖱️ **ドラッグ&ドロップ**: キャラクター名を自由に並び替え、グループ間の移動も可能
- 📜 **コマンド履歴機能**: 生成したコマンドを最大10件まで自動保存
- 📋 **ワンクリックコピー**: 生成したコマンドをクリップボードに簡単コピー
- 📱 **レスポンシブデザイン**: PC・タブレット・スマートフォンで快適に使用可能

## 📖 使い方

### 1. ダウンロード

#### 方法A: ZIPファイルをダウンロード

1. この階層に存在する[ZIPファイル](CharacterChoicer.zip)の画面を開きます
2. 画面右上にあるダウンロードボタンでZIPファイルをダウンロードします
3. Windowsに付属している圧縮ツールやフリーの圧縮ツールでダウンロードしたZIPファイルを展開します

#### 方法B: Gitでクローン

```bash
git clone https://github.com/your-repository/TRPGTools.git
cd TRPGTools/CharacterChoicer
```

### 2. 基本的な使い方

#### ステップ1: ツールを開く

展開したフォルダの中にある`index.html`をブラウザにドラッグ&ドロップするか、ダブルクリックして開きます。

#### ステップ2: キャラクター名を入力

1. **PLキャラクターの名称**テーブルにプレイヤーキャラクターの名前を入力
2. **その他（エネミー等）の名称**テーブルにエネミーやNPCの名前を入力

> 💡 **Tips**:
>
> - 1つの入力欄に1キャラクターの名称を入力してください
> - `+`ボタンで行を追加、`-`ボタンで行を削除できます
> - `名称全削除`ボタンでそのテーブル内の名称を全て削除できます
> - 🖱️ **NEW!** 行をドラッグ&ドロップして並び順を変更できます

#### ステップ3: キャラクターを選択

choiceコマンドに含めたいキャラクター名の左側のチェックボックスをチェックします。

> 💡 **Tips**:
>
> - ヘッダーのチェックボックスでテーブル全体を一括選択できます
> - セルをクリックすることでもチェックボックスを切り替えられます

#### ステップ4: 選択数を指定（オプション）

画面上部の「選択するキャラクター数を入力」欄に数値を入力します。

- **未入力または1**: `choice[キャラA,キャラB,...]`
- **2以上**: `choice2[キャラA,キャラB,...]` （複数選択）

#### ステップ5: コマンドを生成してコピー

1. **作成**ボタンをクリックすると、右側の入力欄にchoiceコマンドが生成されます
2. **コピー**ボタンをクリックすると、コマンドがクリップボードにコピーされます
3. ココフォリアのチャット欄に貼り付けて使用します

> 💡 **新機能**: 生成したコマンドは自動的に履歴に保存されます！

### 3. コマンド履歴の使用

生成したchoiceコマンドは自動的に履歴に保存されます。過去のコマンドを再利用できます。

#### 履歴の表示

1. コントロールエリアの下にある **📜 コマンド履歴（最大10件）** ボタンをクリック
2. アコーディオンが開いて履歴が表示されます

#### 履歴からコピー

1. 履歴一覧から使いたいコマンドを探します
2. 右側の **📋** ボタンをクリックでコピーできます
3. 各履歴項目には生成時刻も表示されます

#### 履歴の管理

- **個別削除**: 各履歴の右上の **✕** ボタンで削除
- **全削除**: 履歴エリア右上の **🗑️ 全削除** ボタンで全ての履歴を削除

> 💡 **Tips**:
>
> - 履歴は最大10件まで保存されます
> - 同じコマンドを生成すると、新しい方が優先されます（重複排除）
> - 古い履歴は自動的に削除されます
> - 履歴もLocalStorageに保存されるため、ブラウザ間で共有されません

### 4. よく使うキャラクター名の保存

頻繁に使用するキャラクター名を保存しておくと、毎回入力する手間が省けます。

#### キャラクターの保存

1. 「よく使うキャラクター名」セクションの**キャラ名**欄に名前を入力
2. **分類**欄にグループ名を入力（例: `PC`, `NPC`, `エネミー` など）
3. **保存**ボタンをクリック

> 💡 **Tips**:
>
> - Enterキーでも保存できます
> - 同じ名前で保存すると上書きされます
> - 分類を空欄にすると「（未分類）」グループに保存されます

#### 保存したキャラクターの使用

1. 保存済みキャラクター一覧から使用したいキャラクターをチェック
2. **選択したキャラクターを上のテーブルに追加する**ボタンをクリック
3. 自動的にPLキャラクターテーブルに追加されます

#### キャラクターの並び替えとグループ移動

**同じグループ内での並び替え:**

1. キャラクター名の行をドラッグ
2. 移動先の行の上にドロップ
3. 自動的に並び順が保存されます

**グループ間での移動:**

1. 移動したいキャラクター名の行をドラッグ
2. 移動先のグループの**ヘッダー部分**（グループ名が表示されている行）にドロップ
3. グループと並び順が自動的に保存されます

> 💡 **Tips**:
>
> - ドロップ可能な場所は視覚的にハイライト表示されます
> - グループヘッダーは緑色に光ります
> - 並び順は自動的に保存されるので、次回も同じ順序で表示されます

#### キャラクターの削除

各キャラクター行の右側にあるゴミ箱アイコンをクリックすると削除できます。

## 🎯 主な機能

### choiceコマンド生成機能

- 複数のキャラクター名から自動的にchoiceコマンドを生成
- 選択数の指定に対応（choice2, choice3, ...）
- ワンクリックでクリップボードにコピー
- **履歴機能**: 生成したコマンドを最大10件まで自動保存
- **履歴から再利用**: 過去のコマンドを簡単にコピー可能

### キャラクター管理機能

- **テーブル形式での入力**: 直感的なテーブルUIで複数のキャラクターを一覧管理
- **動的な行の追加/削除**: 必要な数だけ入力欄を増減可能
- **一括削除機能**: テーブル内の全キャラクター名を一度に削除
- **ドラッグ&ドロップ並び替え**: キャラクター名を自由に並び替え可能

### 保存機能

- **LocalStorageによる永続化**: ブラウザを閉じても保存データは残ります
- **グループ分類**: キャラクターを分類して整理
- **グループ間移動**: ドラッグ&ドロップでキャラクターをグループ間で移動
- **並び順の保存**: カスタマイズした並び順を自動保存
- **後方互換性**: 古いデータ形式も自動的に変換して読み込み

### UI/UX機能

- **レスポンシブデザイン**: スマートフォンでも快適に使用可能
- **キーボードショートカット**: Enterキーで保存など
- **視覚的フィードバック**: ボタンホバー、ドラッグ中の視覚効果など
- **アクセシビリティ対応**: ARIA属性によるスクリーンリーダー対応

## 🔧 技術仕様

### 使用技術

- **HTML5**: セマンティックなマークアップ、テンプレート
- **CSS3**: CSS変数、Flexbox、Grid、アニメーション
- **Vanilla JavaScript (ES6+)**: モジュールパターン、アロー関数、テンプレートリテラル
- **LocalStorage API**: データの永続化
- **Clipboard API**: コマンドのコピー機能
- **HTML5 Drag and Drop API**: ドラッグ&ドロップ機能

### ブラウザ対応

- Chrome 90+
- Firefox 88+
- Edge 90+
- Safari 14+

> ⚠️ **注意**: Internet Explorerには対応していません。

### データ構造

#### キャラクターデータ構造

LocalStorageに以下の形式で保存されます：

```json
[
  {
    "name": "タナカ",
    "group": "PC",
    "order": 0
  },
  {
    "name": "スズキ",
    "group": "NPC",
    "order": 1
  }
]
```

- **name**: キャラクター名（必須）
- **group**: グループ/分類名（省略時は空文字）
- **order**: 並び順を示す数値

> 📝 **後方互換性**: 古い形式（nameとgroupのみ、または文字列のみ）のデータも自動的に新形式に変換されます。

#### コマンド履歴データ構造

```json
[
  {
    "command": "choice[キャラA,キャラB,キャラC]",
    "timestamp": 1697123456789
  }
]
```

- **command**: 生成されたchoiceコマンド文字列
- **timestamp**: 生成時刻（UNIXタイムスタンプ、ミリ秒）

## ❓ よくある質問

### Q1. データはどこに保存されますか？

A1. ブラウザのLocalStorageに保存されます。ブラウザを閉じてもデータは残りますが、ブラウザのキャッシュをクリアすると削除されます。また、他のブラウザやデバイスとは共有されません。

### Q2. データをバックアップできますか？

A2. 現在、エクスポート機能は実装していません。ブラウザの開発者ツール（F12）→ Application → Local Storage から手動でデータを確認・コピーできます。

### Q3. 同じ名前のキャラクターを保存できますか？

A3. 同じ名前で保存すると、既存のデータが上書きされます（更新される形になります）。

### Q4. テーブルに追加できるキャラクター数に制限はありますか？

A4. 技術的な制限はありませんが、パフォーマンスの観点から1テーブルあたり50行程度を推奨します。

### Q5. スマートフォンでも使えますか？

A5. はい。レスポンシブデザインに対応しているため、スマートフォンやタブレットでも快適に使用できます。

### Q6. コピーボタンが動作しません

A6. Clipboard APIに対応していないブラウザや、HTTPSでない環境では動作しない場合があります。その場合は手動でコマンドをコピーしてください。

### Q7. ドラッグ&ドロップがうまく動作しません

A7. 以下を確認してください：

- 最新のブラウザを使用していますか？（古いブラウザでは動作しない場合があります）
- JavaScriptが有効になっていますか？
- ドラッグ開始時に行がしっかり選択されていますか？

### Q8. 並び順が保存されません

A8. ブラウザのLocalStorageが有効になっているか確認してください。また、シークレットモード/プライベートブラウジングモードでは、データが保存されない場合があります。

### Q9. 履歴が表示されません

A9. 以下を確認してください：

- choiceコマンドを生成したことがありますか？（生成時に自動保存されます）
- ブラウザのLocalStorageが有効になっていますか？
- シークレットモードで使用していませんか？

### Q10. 履歴は何件まで保存できますか？

A10. 最大10件まで保存されます。11件目を生成すると、最も古い履歴が自動的に削除されます。

## 🔨 トラブルシューティング

### コマンドが生成されない

**原因**: チェックボックスが選択されていない、またはJavaScriptエラーが発生している

**解決策**:

1. 少なくとも1つ以上のキャラクター名にチェックを入れてください
2. ブラウザの開発者ツール（F12）でコンソールエラーを確認してください
3. ページをリロードしてみてください

### 保存したキャラクターが表示されない

**原因**: LocalStorageが無効、またはデータが破損している

**解決策**:

1. ブラウザの設定でLocalStorageを有効にしてください
2. シークレットモード/プライベートブラウジングモードではなく、通常モードで使用してください
3. ブラウザのキャッシュをクリアして、再度保存してみてください

### コピーボタンが反応しない

**原因**: Clipboard APIが利用できない環境

**解決策**:

1. HTTPSで提供されているページで使用してください（file://では動作しない場合があります）
2. 最新のブラウザを使用してください
3. 手動でテキストを選択してコピーしてください

### choiceコマンドではなくchoice2などになってしまう

**原因**: 選択数の入力欄に2以上の数値が入力されている

**解決策**:

1. 選択数の入力欄に2以上の数値を入力してください
2. 空欄の場合は自動的にchoice（choice1相当）が生成されます

### ドラッグ&ドロップが動作しない

**原因**: ブラウザがHTML5 Drag and Drop APIに対応していない、またはJavaScriptエラーが発生している

**解決策**:

1. 最新のブラウザ（Chrome 90+, Firefox 88+, Edge 90+, Safari 14+）を使用してください
2. ブラウザの開発者ツール（F12）でコンソールエラーを確認してください
3. ページをリロードしてみてください（Ctrl+F5 / Cmd+Shift+R）

### グループ間でキャラクターが移動できない

**原因**: グループヘッダー（グループ名）以外の場所にドロップしている

**解決策**:

1. キャラクター名をドラッグします
2. 移動先のグループの**ヘッダー部分**（グループ名が表示されている行）にドロップしてください
3. ヘッダーが緑色に光る場所でドロップできます

### 履歴が保存されない

**原因**: ブラウザのLocalStorageが無効、またはストレージ容量が不足している

**解決策**:

1. ブラウザの設定でLocalStorageを有効にしてください
2. ブラウザのキャッシュを整理してストレージ容量を確保してください
3. シークレットモードではなく通常モードで使用してください
