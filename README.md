## このリポジトリについて

- 各フォルダが1つのツールです（例: `AR2EEnemyCreator` はアリアンロッド2Eのエネミー作成ツール）。
- すべてブラウザだけで動きます。インストールやサーバー構築は一切不要です。
- ブックマークレット方式と、ZIPを解凍して `index.html` を開く方式の2通りで利用できます。

## ブックマークレットとして使うツールの使い方

ブラウザの「ブックマーク」に登録して、必要なページでクリックして使うやり方です。

1. GitHubで目的のツールフォルダを開き、`script.js` を表示します。
2. 右上にある **Raw** ボタンかコピーアイコンを押して、コードをすべてコピーします。
    1. ![コピーボタン](../images/images/fileCopyImage.png)
3. ブラウザで適当なページを開き、ブックマーク（お気に入り）を新規作成します。
4. ブックマーク名をわかりやすく変更し、URL欄にコピーしたコードを貼り付けて保存します。
5. ツールを使いたいページで、そのブックマークをクリックすることでZIPファイルがダウンロードされます。

> うまく動かないときは、ポップアップブロックやセキュリティ拡張機能を一時的にOFFにすると改善する場合があります。

## スタンドアロン（ZIP版）として使うツールの使い方

1. GitHubの右上にある **Code** ▸ **Download ZIP** をクリックし、リポジトリ全体をダウンロードします。（もしくは各ツールの README にある「Download ZIP」リンクでもOK）
2. ダウンロードしたZIPを任意のフォルダに解凍します。
3. 使いたいツールのフォルダ（例: `AR2EEnemyCreator`）を開きます。
4. `index.html` をブラウザへドラッグ＆ドロップするか、右クリックして「このアプリケーションで開く」からブラウザを選択します。
5. 画面が表示されたら案内に従って入力します。データはブラウザのローカルストレージに保存されるため、ブラウザを閉じても次回また開けば続きから操作できます。

## ユドナリウムへ読み込む手順

1. 各ツールで「ZIPダウンロード」や「エクスポート」ボタンを押し、ユドナリウム用ZIPファイルを作成します。
2. ブラウザでユドナリウムを開き、表示されているテーブルにZIPファイルをドラッグ＆ドロップします。
3. 駒（キャラクター／エネミー）が追加されます。画像は付属していないため、必要に応じてユドナリウム側で設定してください。

## よくある質問

**Q1. ブックマークレットを押しても何も起きません。**
A. ポップアップやスクリプトをブロックする拡張機能が原因の場合があります。別のページで試すか、ブロックを一時的に解除してください。

**Q2. ZIPを解凍できません。**
A. WindowsならZIPファイルを右クリックして「すべて展開」、macOSならダブルクリックで解凍できます。7-Zipなどの解凍ソフトを使っても構いません。

**Q3. 作ったデータはどこに保存されていますか？**
A. ブラウザのローカルストレージに保存されます。別PCへ移動したいときは、ツール内のエクスポート機能でJSONを保存し、新しいPCでインポートしてください。

**Q4. 画像はどうすればいいですか？**
A. 画像は同梱していません。ユドナリウムに駒を読み込んだ後、ユドナリウム側で好きな画像を設定してください。
