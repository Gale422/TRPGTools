# アリアンロッド2E エネミー作成ツール

アリアンロッド2E（Arianrhod 2E）のエネミーデータをブラウザだけで作成・管理し、ユドナリウム用XML/ZIPとチャットパレットを一貫して生成できる支援ツールです。オフライン環境でも動作します（初回のみ外部ライブラリの読込にネット接続が必要）。

## 概要

- ブラウザだけで完結する単一HTMLアプリ。インストール不要・保存先はローカルストレージ。
- `エネミー管理` と `スキル・パワー管理` の2タブ構成。ライブラリ化したスキルを複数のエネミーで共有可能。
- ユドナリウムにそのまま読み込めるXMLを生成し、単体/複数ZIP出力、プレビュー確認、カスタムチャットパレット拡張、バフデバフの定型コマンド自動出力に対応。
- すべてのデータをJSON形式でエクスポート/インポートでき、最終更新日優先マージで衝突を解決可能。
- 主要ライブラリ: JSZip 3.10.1, FileSaver.js 2.0.5（CDN経由）。

## 導入・起動方法

### スタンドアロン（ZIP版）

1. GitHubリポジトリで **Code ▸ Download ZIP** を押し、任意のフォルダに展開する。
2. `AR2EEnemyCreator` ディレクトリを開き、`index.html` をブラウザへドラッグ＆ドロップするか `python3 -m http.server 4173` 等でローカルサーブしてアクセスする。
3. 初回アクセス時にJSZipとFileSaver.jsをCDNから取得するため、ネットワーク接続を有効にしておく（2回目以降はキャッシュで動作）。

## 画面構成

| エリア | 役割 |
| --- | --- |
| エネミー管理タブ | エネミー一覧の検索・複製・削除・ZIP/XMLダウンロード・チェックボックス選択による一括エクスポート、新規作成フォームの表示を行います。フォームは固定ヘッダーで、保存/キャンセル/ZIPダウンロード/XMLダウンロード/プレビューの操作ボタンが並びます。 |
| スキル・パワー管理タブ | 汎用スキルをライブラリとして管理。検索、複製、編集、削除、並び替え、ライブラリからエネミーに挿入するためのモーダルを提供します。 |
| フッター | データ管理メニュー（全データ/スキルライブラリのエクスポート・インポート・最終更新日優先マージ・全データ削除）と著作権表記・利用上の注意を常時表示し、生成データの再頒布禁止などを明示しています。 |

モーダルウィンドウは (1) 確認・警告モーダル、(2) スキル選択モーダル、(3) XMLプレビューモーダル の3種類を装備し、すべてキーボードフォーカスに追従します。

## 主な機能

### エネミー作成ワークフロー

- エネミー名・レベル・分類などの基本情報から、リソース・能力値・ドロップ品・スキル・メモまで1画面で編集可能。
- モブエネミー用に「アクション/リアクション」入力モードを用意し、レベル入力時に自動で `(モブ)` を付加。
- 敏捷+感知で行動値基本値、筋力+5で移動力基本値を自動計算。任意で手動入力へ切り替え可能。
- ドロップ品は行を追加しながら下限/上限・価格・個数を設定。昇順ソート、範囲の穴/重複チェック、最小値2の検証を自動化。
- エネミー一覧ではチェックボックスで複数選択すると「選択したエネミーを一括エクスポート」ボタンが表示され、個別のZIPをまとめたZIPを生成できます。

### スキル・パワーライブラリ

- ライブラリはブラウザ内で永続化され、タイミング順+名称順で自動ソート。
- 共有スキルを検索してモーダルからエネミーに追加、既存スキルの複製・削除・再利用、SLや判定情報のテンプレート化が可能。
- ライブラリ単体のJSONエクスポート/インポートを提供し、通常マージと最終更新日優先マージを選択できます。

### ドロップ表とリソース自動計算

- 能力基本値入力時は `⌊基本値/3⌋` を自動計算して表示し、スライダー的プレビューで現在値を即確認。
- 行動値/移動力は基本値と補正値の入力欄を分け、装備補正と固定値を見比べながら微調整可能。
- ドロップテーブルは入力時にエラー箇所へ警告を表示し、XML出力時も検証を行います。

### チャットパレットとバフデバフ

- 判定/ダメージコマンドは固定値とボーナスを入力するたびにリアルタイムプレビューされ、チャットパレットへ `{スキル名}` 形式で埋め込み。
- 各判定/ダメージコマンドのヘッダーラベルでチャットパレット表記（任意）を直接編集でき、空欄時は従来の自動番号と継承ルールで整理されます。
- 「カスタムチャットパレットコマンド」欄に任意の行を記述すると、チャットパレット内のカスタムセクションにそのまま出力。
- バフデバフパレットUIでバフ名・効果・R数を入力し、対象指定（`t&`）や削除コマンドをワンクリックで生成。汎用バフ操作コマンドは自動で付与されます。

### プレビューとエクスポート

- 保存済みエネミーは「プレビュー」ボタンからXML全体をシンタックスハイライト付きで確認できます。モーダルはドラッグ移動可能。
- `ZIP` ボタンはエネミーごとのXMLをZIP化してダウンロード。複数選択時は個別ZIPを二重ZIPにまとめ、`enemies_YYYYMMDD.zip` を生成します。
- `XML` ボタンはZIPを介さずに `エネミー名.xml` を直接ダウンロードします。Windows Defenderのブロック（MOTW）を回避したい場合はこちらのファイルを利用し、自身でZIP化してください。
- XMLにはチャットパレット、バフパレット、能力値、詳細情報、ドロップ品などすべての入力内容が反映されます。

## 入力項目の詳細

### 基本情報

- **エネミー名（必須）**: 文字列。保存やZIP出力時のファイル名にも使用。
- **レベル**: 整数または `1(モブ)` 形式。モブチェックONで自動追従。
- **分類/属性/掲載ページ/識別値/サイズ**: 文字列または数値。サイズは1〜5。

### リソース

- **HP / MP / 行動値 / 移動力 / 物理防御力 / 魔法防御力** を保持。
- 行動値/移動力は「基本値（自動）＋補正値＝最終値」の構造で、チェックボックスで直接入力に切り替え可能。

### 能力値

- **能力基本値で入力**: 筋力〜幸運の基本値を入力すると能力値を自動算出。
- **能力値で入力**: 直接能力値を入力。
- **アクション/リアクションで入力**: モブ向け。アクション値・リアクション値のみ入力。

### ドロップ品

- 行ごとに「下限値 / 上限値 / アイテム名 / 価格 / 個数」を入力。「ドロップ品を追加」で複数行を管理。
- 価格は数値なら `1,000G` 形式、文字列（非売品など）はそのまま出力。
- 自動機能: 下限昇順ソート、範囲欠損チェック、最小値2の検証、`妖精の羽(10G)` のようなXML出力。

### スキル・パワー

- 必須: スキル名 / 判定 / 対象 / 射程 / SL / 効果。
- 任意: タイミング、分類、コスト、使用条件、判定コマンド、ダメージコマンド、クリティカル処理、コスト0自動変換など。
- ライブラリからの取り込み、並び替え（↑↓）、複製、削除をサポート。
- 「通常武器攻撃を追加」ボタンで、ライブラリに登録せず専用カードを作成可能。武器種別・装備部位・攻撃方法・ダメージ種別を入力すると《スキル名》(種別/装備/攻撃方法/ダメージ)の形式でXMLへ出力され、タイミング/コスト/SL/使用条件/効果/クリティカルはツールが固定値を自動設定する。

### メモ・カスタムコマンド

- セッションごとの補足を自由記述。
- カスタムチャットパレット欄は行ごとにコマンド＋説明を記載でき、バフデバフパレットで作成した行もここに追記されます。

## データ保存と入出力

- データ保存先: ブラウザのローカルストレージ。
  - エネミー: `ar2e_enemies`
  - スキルライブラリ: `ar2e_skills`
- ブラウザや端末を変えると共有されません。データを初期化したい場合はブラウザのサイトデータ設定（例: `chrome://settings/siteData`）から該当ドメインのストレージを削除してください。

### 全データエクスポート/インポート

1. `全データエクスポート` で `ar2e_data_YYYY-MM-DD.json` をダウンロード。
2. `全データインポート` では (a) マージ、(b) 上書き、(c) キャンセルを三択モーダルで選択。
3. マージ選択時はさらに「通常マージ」か「最終更新日優先マージ」を選ぶ。後者は `updatedAt`（無ければ`createdAt`）が新しいデータを優先。
4. インポート後はエネミー一覧・スキルライブラリが再描画されます。

### スキルライブラリ単体の入出力

- `スキルライブラリエクスポート` / `インポート` ボタンでライブラリのみを扱うJSONを出力/入力。
- インポート時も通常マージ / 最終更新日優先マージ / 上書きを選択可能。

### 全データ削除

- `全データ削除` でエネミー・スキルライブラリ両方を完全消去。取り消し不可です。

### 一括ZIPエクスポート

- エネミー一覧でチェックボックスをONにすると「選択したエネミーを一括エクスポート」ボタンが現れます。
- それぞれのXMLを個別ZIPにし、さらに1つのZIP (`enemies_YYYYMMDD.zip`) にまとめてダウンロードします。

## チャットパレットとXML/ZIP出力の構成

- 受動判定（回避/ダメージ適用）→能動判定→バフ関連→カスタム→識別公開情報→エネミースキル→ドロップ品の順にチャットパレットを自動生成。
- スキル行は `{スキル名}` でnote要素と連動し、チャットパレットの1行目が空にならないよう最適化済み。
- バフ関連セクションには `&R+` などの定型コマンドと、バフデバフパレットで生成したコマンドがまとまって出力されます。
- XML内では全要素を開始/終了タグ形式に統一し、ユドナリウムでの読み込みを安定化。
- プレビューはXML宣言・コメント・CDATAを色分け表示し、空要素は実際のXMLと同じフォーマットで確認できます。

## トラブルシューティング

- **ダウンロードが開始されない**: ポップアップブロックやスクリプトブロック系拡張機能を無効化し、別タブで再試行してください。
- **ZIPを解凍できない**: Windowsは右クリック→「すべて展開」、macOSはダブルクリックで解凍可能です。7-Zip等のツールでも問題ありません。
- **WindowsでZIP展開後にXMLがブロックされる**: ZIPを展開する前に右クリック→「プロパティ」で「ブロックの解除」にチェックを入れてください。解除前に展開した場合は PowerShell の `Unblock-File -Path "展開先\\*.xml" -Recurse` で削除できます。もしくは「XMLダウンロード」ボタンで直接取得し、ローカルでZIP化してください（MOTWが付与されません）。
- **データが消えた/表示されない**: ブラウザのローカルストレージを削除した可能性があります。JSONバックアップからインポートしてください。シークレットモードでは保存されません。
- **ZIP生成に失敗する**: 初回アクセスでネットワークに繋がっているか確認し、ブラウザコンソールのエラー（JSZip/FileSaverの読み込み失敗など）を確認してください。
- **インポート時にエラー**: JSONの形式が `enemies` / `skills` を含むか確認し、UTF-8で保存されたファイルを使用してください。
- **XMLプレビューが真っ白になる**: 新規作成中はプレビューボタンが表示されません。保存後に再度編集し、ブラウザのダークモード拡張が干渉していないか確認してください。
- **画像がない**: ユドナリウム側で任意の画像を設定してください（本ツールでは画像を同梱しません）。
