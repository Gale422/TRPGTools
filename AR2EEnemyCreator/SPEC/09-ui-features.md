### UI/UX機能

> **関連仕様**:
>
> - [モーダルウィンドウ](#モーダルウィンドウ)は[ライブラリからのスキル選択](#ライブラリからのスキル選択)、[データ管理](#データ管理)のインポート確認などで使用される
> - [固定ヘッダー](#固定ヘッダー)はエネミー編集画面とスキルライブラリ編集画面に適用される
> - [ダブルクリックで編集](#ダブルクリックで編集)は[エネミー管理機能](#エネミー管理機能)と[スキル・パワーライブラリ管理機能](#スキルパワーライブラリ管理機能)で使用される

#### モーダルウィンドウ

- 削除確認などの重要な操作はモーダルウィンドウで確認
- アラート形式は廃止
- **ボタン内での改行禁止方針**:
  - ボタン内のテキストは基本的に改行しない（`white-space: nowrap`を適用）
  - ボタンが横並びで表示される場合は、モーダルの幅を調整してボタンが1行に収まるようにする
  - マージ方法選択などの複数ボタンが表示される場合は、`modal-large`クラスを適用してモーダル幅を拡大（`800px`）
  - モバイル表示（768px以下）ではボタンを縦並びにし、ボタン内の文字は改行しない
  - 非常に小さい画面（320px以下）の場合のみ、ボタン内の文字を改行可能にする（`white-space: normal`）
  - この方針により、ユーザーにとって読みやすく操作しやすいUIを維持する

#### 固定ヘッダー

- エネミー編集画面とスキル・パワーライブラリ編集画面のヘッダー部分を固定表示
- ページをスクロールしても「保存」「キャンセル」「ZIPダウンロード」「XMLダウンロード」などのボタンが常に上部に表示される
- `position: sticky`を使用してスクロールに追従
- 固定ヘッダーの実装:
  - `.enemy-form-section`と`.skill-library-form-section`がスクロールコンテナ
  - `.section-header.sticky`が固定ヘッダー（`z-index: 100`）
  - ビューポート基準の高さ設定: `max-height: calc(100vh - 12vh)`
- レスポンシブ対応:
  - デスクトップ（1401px以上）: 見出しとボタンが横並び、横幅が足りなければ折り返し
  - タブレット/モバイル（1400px以下）: 見出しとボタンが縦並び
  - ボタンは`white-space: nowrap`で改行を防止
  - 折り返し時はボタンが右寄せ（`margin-left: auto`）
- モバイル表示でも適切に動作

#### レスポンシブレイアウト

- ビューポート単位（vw/vh）を使用した柔軟なレイアウト
- コンテナの幅: `max-width: 98vw`（画面サイズに応じて自動調整）
- 余白とpadding: `2vw`、`2vh`など、画面サイズに比例
- モバイル表示: `max-width: 99vw`でより広く表示
- 左右の背景を最小限に抑え、コンテンツ領域を最大化

#### ダブルクリックで編集

- エネミー一覧とスキル・パワーライブラリ一覧のカードをダブルクリックすることで編集画面を開ける
- ダブルクリックイベント（`dblclick`）を使用
- カードに`cursor: pointer`を設定し、クリック可能であることを視覚的に示す
- シングルクリックでは何も起こらない（既存の動作を維持）
- ダブルクリック時は編集ボタンをクリックした場合と同じ動作をする
- 実装:
  - `.enemy-item`に`data-enemy-id`属性を追加
  - `.skill-library-item`に`data-skill-id`属性を追加
  - `_attachEnemyDoubleClickHandlers()`メソッドでイベントリスナーを登録
  - `_attachSkillDoubleClickHandlers()`メソッドでイベントリスナーを登録

#### メモ機能

- エネミー編集画面の最下部に「メモ」セクションを配置
- 自由記述のテキストエリア（4行）で、GMメモなどを記述可能
- メモの内容はエネミーデータに保存されるが、XML出力には含まれない
- 編集時に自動的に読み込まれ、次回編集時も参照可能

#### チャットパレットへのカスタムコマンド追加

> **関連仕様**:
>
> - 入力されたコマンドは[XML生成とエクスポート](#xml生成とエクスポート)の[チャットパレットの構造](#チャットパレットの構造)の「カスタム」セクションに出力される
> - [バフデバフパレット](#バフデバフパレット)で生成されたコマンドもここに追加される

- エネミー編集画面のメモセクションの上に「カスタムチャットパレットコマンド」セクションを追加
- 自由記述のテキストエリア（8行）で、チャットパレットに追加したいコマンドを記述可能
- 用途例:
  - バフ付与コマンドのバリエーション（効果強度別）
  - セッション固有のカスタムコマンド
- XML出力時の配置順序:
  1. 受動判定セクション
  2. 能動判定セクション
  3. バフ関連セクション
  4. **カスタムセクション**（ここにカスタムコマンドが追加される）
  5. 識別公開情報セクション
  6. エネミースキルセクション
  7. ドロップ品セクション
- 入力内容は行ごとに分割され、空行は自動的にスキップされる
- カスタムコマンドはエネミーデータに保存され、編集時に自動的に読み込まれる

#### テンプレートタグ化

- HTML文字列をJavaScriptから分離し、`<template>`タグを使用してテンプレートとして管理
- 実装内容:
  - `index.html`に以下のテンプレートを追加:
    - `template-enemy-empty-state`: エネミー一覧の空状態
    - `template-enemy-item`: エネミーカード
    - `template-skill-item`: スキルアイテム
    - `template-judge-command`: 判定コマンド
    - `template-damage-command`: ダメージコマンド
    - `template-drop-item-row`: ドロップ品テーブル行
    - `template-skill-select-empty-state`: スキル選択リストの空状態
    - `template-skill-select-item`: スキル選択アイテム
    - `template-skill-library-empty-state`: スキルライブラリ一覧の空状態
    - `template-skill-library-item`: スキルライブラリアイテム
  - JavaScript側で`template.content.cloneNode(true)`を使用してテンプレートをクローン
  - HTMLからJavaScriptのイベント属性（onclick、onchange、oninput）を削除
  - すべてのイベント処理をJavaScript側で`addEventListener`を使用して設定
- メリット:
  - HTMLとJavaScriptの分離による可読性・保守性の向上
  - テンプレートの一元管理による変更時の影響範囲の明確化
  - XSS対策: `innerHTML`への文字列挿入を削減

#### バフデバフパレット

> **関連仕様**:
>
> - 生成されたバフコマンドは[チャットパレットへのカスタムコマンド追加](#チャットパレットへのカスタムコマンド追加)の`customCommands`フィールドに保存される
> - XML出力時は[チャットパレットの構造](#チャットパレットの構造)の「バフ関連」セクションに自動的に追加される

- カスタムチャットパレットコマンドセクションの下に「バフデバフパレット」セクションを追加
- バフ名、効果、R数を入力してバフコマンドを自動生成
- 「対象にバフを付与」チェックボックスで`t&`プレフィックスの追加を選択可能
- バフコマンドの形式:
  - `&バフ名` - バフ名のみ
  - `&バフ名/効果` - バフ名と効果
  - `&バフ名/効果/R数` - バフ名と効果とR数
  - `t&バフ名/効果/R数` - 対象にバフを付与（対象チェック時）
- 「バフを追加」ボタン: バフコマンドを生成し、カスタムチャットパレットに自動追加
- 「バフ削除コマンドを追加」ボタン: `&バフ名-`または`t&バフ名-`コマンドをカスタムチャットパレットに追加
- バフコマンドは`customCommands`フィールドに保存され、編集時に自動的に読み込まれる
- XML出力時に「バフ関連」セクションに自動的に追加されるコマンド:
  - 一般的なバフ操作コマンド:
    - `&バフ名/効果/R数 バフ追加`
    - `&バフ名- バフ消去`
    - `&R- バフラウンド-1`
    - `&R+ バフラウンド+1`
    - `&D 0R以下のバフ消去`
    - `&R- &D バフのラウンド進行`
    - `t&バフ名/効果/R数 対象にバフ追加`
    - `t&バフ名- 対象のバフ消去`
    - `t&R- 対象のバフラウンド-1`
    - `t&R+ 対象のバフラウンド+1`
    - `t&D 対象の0R以下のバフ消去`
    - `t&R- t&D 対象のバフのラウンド進行`
  - 特定のバフ削除コマンド（自動回復タイミング付き）:
    - `&縛鎖- セットアップ終了時に自動的に回復`
    - `&スタン- イニシアチブの権利を得た際に自動的に回復`
    - `&スリップ- ムーブ使用時に回復`
    - `&威圧- マイナー使用時に回復`
    - `&狂戦士化- マイナー使用時に回復`
    - `&恐怖- メインプロセス終了時に自動的に回復`
    - `&逆上- &ノックバック- &放心- クリンナップで自動的に回復`
    - `&毒-`
    - `&衰弱-`
- これらのコマンドは自動的に追加されるため、UI上でのボタンは不要

#### プレビュー機能

> **関連仕様**:
>
> - [XML生成とエクスポート](#xml生成とエクスポート)で生成されるXMLをプレビュー表示する
> - プレビューはモーダルウィンドウで表示され、ドラッグで移動可能
> - プレビューは表示専用機能であり、XMLファイルの実体は各エネミーの「ZIPダウンロード」または「XMLダウンロード」機能から取得する（プレビュー表示と同じ内容がダウンロードファイルに出力される）

- エネミー編集画面に「プレビュー」ボタンを追加
- プレビューボタンをクリックすると、現在のフォームデータから生成されるXML全体をプレビュー表示
- プレビューは**保存済みのエネミーを編集している場合のみ**利用可能。新規作成中はボタンを非表示にし、保存後に再度編集画面を開いたタイミングでフォーム内容をプレビューする
- **XMLシンタックスハイライト**: XMLの要素を色分けして表示
  - タグ名: 青（`#569cd6`）
  - 属性名: 薄い青（`#9cdcfe`）
  - 属性値: オレンジ（`#ce9178`）
  - テキストコンテンツ: 白（`#d4d4d4`）
  - XML宣言: グレー（`#808080`）
  - コメント: 緑（`#6a9955`）
  - CDATA: 黄色（`#d7ba7d`）
- **モーダルウィンドウ**:
  - 初期表示は画面中央
  - モーダルヘッダーをドラッグして画面内で移動可能
  - 画面外に出ないように制限
- **XML文字実体参照**: XML文字実体参照（`&amp;`、`&lt;`、`&gt;`など）はそのまま表示（変換しない）
- **XMLフォーマット**:
  - 改行処理: 実装済み（子要素がない場合は開始タグと終了タグを同一行。子要素を持つ可能性がある要素は空でも改行してブロック表示）
  - インデント処理: 実装済み（2スペース単位）

#### 著作権注意文の表示

- フッター領域に`.license-notice`コンテナを常時表示し、著作権者情報と利用上の注意をまとめて掲出する。
- 表示文言は`script.js`の`COPYRIGHT_NOTICE`定数で一元管理する。`heading`（見出し）と`messages`（段落）をUI初期化時に`UIManager._renderCopyrightNotice()`が描画する。
- 既定の文言:
  1. 「アリアンロッド2Eの著作権は 菊池たけし / F.E.A.R. に帰属します。本ツールは非公式のファンメイドです。」
  2. 「本ツールで生成したデータ（XML / ZIP / JSON など）は個人セッションなどの私的利用に限定し、第三者への再頒布や公的配布を行わないでください。」
  3. 「公式ルールブックやサプリメントを引用する場合は、引用範囲と出典表記を利用者自身の責任で行い、著作権者が定める条件に従ってください。」
- DOM描画時はいったん要素を空にしたうえで見出し・各段落を生成し、将来的な多言語化や差し替えでもUI崩れが起きないようにする。
- スタイルは`style.css`内の`.license-notice__heading` / `.license-notice__message`で定義し、背景透過と枠線で他要素との差別化を図る。
