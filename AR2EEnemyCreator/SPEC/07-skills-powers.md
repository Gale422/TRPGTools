### スキル・パワーの管理

> **関連仕様**:
>
> - [スキル・パワーライブラリ](#スキルパワーライブラリ)から[ライブラリからのスキル選択](#ライブラリからのスキル選択)でエネミーに追加可能
> - スキルの[判定用コマンドとダメージコマンド](#判定用コマンドとダメージコマンド)は[XML生成とエクスポート](08-xml-generation.md#xml生成とエクスポート)でチャットパレットに出力される
> - スキルの詳細は[スキル・パワーのnote要素](08-xml-generation.md#スキルパワーのnote要素)としてXMLに出力される
> - [タイミングの種類](#タイミングの種類)でグループ化され、チャットパレットに表示される

#### スキル・パワーライブラリ

汎用的なスキル・パワーを登録・管理するライブラリ機能:

- スキル・パワーの新規作成・編集・複製・削除
- タイミング順で自動ソート
- エネミーデータ作成時にライブラリから選択して追加可能
- スキルごとに「クリティカル時の処理」（ダイスロール増加/コスト0/カスタム+自由入力）を登録・編集し、エネミー編集でライブラリから追加した際のデフォルト値として利用

#### ライブラリからのスキル選択

- エネミー編集画面の「ライブラリから選択」ボタンをクリックすると、スキル選択モーダルが表示される
- モーダル内に検索ボックスがあり、スキル名でリアルタイム検索が可能
- スキル一覧には、タイミングバッジ、スキル名、効果（100文字まで表示）が表示される
- スキルをクリックすると、そのスキルがエネミーに追加され、モーダルが閉じる
- 追加されたスキルは、エネミーのスキル一覧に表示され、編集・削除が可能
- エネミー側での初期表示時は、ライブラリに保存されているクリティカル設定を自動で反映しつつ、必要に応じて個別に上書きできる
- モーダルは「キャンセル」ボタンで閉じることができる

#### タイミングの種類

- **入力方法**: ドロップダウンから選択、または自由入力
- **ドロップダウンの選択肢**: ―、パッシブ、セットアップ、イニシアチブ、フリー、ムーブ、レガシー、マイナー、メジャー、判定の直前、判定の直後、DRの直前、DRの直後、リアクション、クリンナップ、戦闘不能、効果参照
- **補足**: ドロップダウンにない値も自由に入力可能（新しいタイミングや独自の表記にも対応）

#### 必須項目

- スキル名
- 判定
- 対象
- 射程
- SL（スキルレベル、正の整数、初期値1）
- 効果

#### 通常武器攻撃カード

- エネミー編集画面の「通常武器攻撃を追加」ボタンでのみ作成できる。スキル・パワーライブラリには登録されず、エネミーデータに直接紐付く。
- 追加直後から以下のフィールドはツールが固定値を適用し、ユーザーは編集できない:
  - タイミング: メジャー
  - コスト: 0（XMLでは`[コスト:―]`）
  - SL: `-`
  - 使用条件: `―`
  - 効果: `対象に武器攻撃を行う。`
  - クリティカル処理: `ダイスロール増加`
- 判定・対象・射程・判定/ダメージコマンドは通常スキルと同じUIを共有し、必要に応じて編集できる。
- 「通常武器攻撃のメタ情報」ブロックでは以下4項目を入力でき、空欄は自動的に省略される:
  1. 武器種別（例: 長剣）
  2. 装備部位（例: 片 / 両）
  3. 攻撃方法（例: 白兵 / 射撃）
  4. ダメージ種別（例: 物理 / 魔法）
- メタ項目は`《スキル名》(種別/装備/攻撃方法/ダメージ)`という形式でスキル名の後ろに連結され、チャットパレット・XMLプレビュー・ZIP内XMLで同一表記となる。
- 生成されたスキルカードは視覚的に区別できるよう枠線・バッジを警告色に変更し、固定値フィールドはグレー背景（readonly）で表示する。
- 武器種別、装備部位、攻撃方法、ダメージ種別はドロップダウンから選択もできるし、自由に入力することもできる。挙動としてはスキルの判定と同一。
- 武器種別、装備部位、攻撃方法、ダメージ種別は空になる場合がある。例えば武器種別と装備部位が空になる場合は`(攻撃方法/ダメージ種別)`となる
- 分類はメタ項目の後に表示されるため、分類が入力されている場合は`《スキル名》(種別/装備/攻撃方法/ダメージ)[分類:ユーザーの入力値])]`という形になる
- 武器種別の選択肢
  - 格闘
  - 短剣
  - 長剣
  - 両手剣
  - 斧
  - 打撃
  - 槍
  - 鞭
  - 弓
  - 刀
  - 魔導銃
  - 錬金銃
  - 錬金術
- 装備部位の選択肢
  - 片
  - 両
  - 双
- 攻撃方法の選択肢
  - 白兵
  - 射撃
  - 投擲
  - 魔法
  - 特殊
- ダメージ種別の選択肢
  - 物理
  - 魔法
  - 貫通

#### 判定の種類

- **入力方法**: ドロップダウンから選択、または自由入力
- **ドロップダウンの選択肢**: ―、自動成功、命中判定、魔術判定、錬金術判定、呪歌判定、回避判定、各種能力値判定（筋力判定、器用判定、敏捷判定、知力判定、感知判定、精神判定、幸運判定）、効果参照
- **補足**: ドロップダウンにない判定タイプも自由に入力可能（ただし、自動計算される固定値は標準的な判定タイプのみ対応）

#### コスト

- 正の整数のみ入力可能
- 初期値は0
- 0の場合、XMLでは`―`として出力

#### 判定用コマンドとダメージコマンド

> **関連仕様**:
>
> - 固定値の自動算出は[能力値の管理](04-abilities.md#能力値の管理)の能力値を参照する
> - モブエネミーの場合は[モブエネミーの能力値](04-abilities.md#モブエネミーの能力値)のアクション/リアクションを参照する必要がある（未実装: [モブエネミーの固定値自動算出の改善](TODO.md#モブエネミーの固定値自動算出の改善)）
> - 生成されたコマンドは[XML生成とエクスポート](08-xml-generation.md#xml生成とエクスポート)の[チャットパレットの構造](08-xml-generation.md#チャットパレットの構造)に出力される
> - 判定コマンドとダメージコマンドには任意のチャットパレット表記（デフォルトは《スキル名》）を設定でき、空欄時は自動ルールに従う

**構造**:

```txt
スキル
  └─ 判定コマンド 1..n個
       └─ ダメージコマンド 0..n個
```

**判定コマンド**:

- 判定が`―`または`自動成功`の場合は0個
- 判定が`効果参照`の場合は0個以上
- それ以外は1個以上
- 各判定コマンドには以下の情報を設定:
  - ダイス数（デフォルト2）
  - 固定値（自動算出または直接入力）
  - 補正値
- 固定値の自動算出ルール:
  - 命中判定 → 器用
  - 魔術判定 → 知力
  - 錬金術判定 → 器用
  - 呪歌判定 → 精神
  - 回避判定 → 敏捷
  - 各種能力値判定 → それぞれの能力値
- UI機能:
  - 「判定コマンド追加」ボタンで複数の判定コマンドを動的に追加可能
  - 各判定コマンドに削除ボタンがあり、個別に削除可能
  - 固定値の自動算出/直接入力はチェックボックスで切り替え
  - チェックボックスON時: 判定タイプから能力値を自動算出（例: `{器用}`）
  - チェックボックスOFF時: 固定値を直接入力可能
  - リアルタイムプレビュー機能で判定コマンドの形式を確認可能（例: `2D6+{器用}+2>=?`）
- ヘッダー左側の入力欄（プレースホルダー「チャットパレット表記（任意）」）でチャットパレット表記を丸ごと編集できる。初期値は `判定タイプ 《スキル名》`（2件目以降は自動で `(2)` 付き）
- 入力欄の右に「デフォルトに戻す」ボタンを配置し、クリックで初期表記へ即座に戻せる

**ダメージコマンド**:

- 各判定コマンドに0個以上紐づく
- ダイス数、固定値、補正値を設定可能
- 新規追加時のダイス数は2（初期状態で`2D`想定のダメージロールを編集できる）
- UI機能:
  - 「ダメージ追加」ボタンで複数のダメージコマンドを動的に追加可能
  - 各ダメージコマンドに削除ボタンがあり、個別に削除可能
  - リアルタイムプレビュー機能でダメージコマンドの形式を確認可能（例: `3D6+10`）
- ダメージコマンドのヘッダーにも同じ入力欄と「デフォルトに戻す」ボタンを配置し、初期値は `ダメージ 《スキル名》`（2件目以降は「判定2-ダメージ2」などの注記付き）

**チャットパレット出力**:

```txt
2D6+{固定値}+{補正値}>=? 《スキル名》
3D6+10 ダメージ《スキル名》
```

**表記ルール**:

- 判定行/ダメージ行ともに `《{表示名}》` の形式で出力する。
- 表示名は各コマンドの入力欄の値をそのまま使用する。空欄の場合のみ自動的に `判定タイプ 《スキル名》` または `ダメージ 《スキル名》`（複数ある場合は `(2)` や `（ダメージ2）` を付与）を挿入する。
- システム側で `《》` を自動付与しないため、必要に応じてユーザーが入力欄内で整形する。

#### クリティカル時の処理

- 判定が`―`または`自動成功`の場合は設定不要
- 判定が`効果参照`の場合は、チェックボックスでON/OFFを切り替え可能
- デフォルト選択:
  - ライブラリから追加したスキル: スキル・パワーライブラリに登録されているクリティカル設定をそのまま初期値として反映
  - ライブラリ未登録またはクリティカル未指定のスキル: ダメージコマンドを持つスキルは`ダイスロール増加`、それ以外は`コスト0`を初期値とする
- カスタム処理:
  - 「カスタム処理」ラジオボタンの右側に常時入力欄を表示し、自由入力テキストを保存できるようにする
  - XML出力時は`【クリティカル:{ユーザーが入力したカスタム文言}】`の形式で他のクリティカル表記と統一する

#### スキル・パワー名の重複チェック

- 1つのエネミーに同名のスキル・パワーが存在する場合はエラー
- XMLのプロパティ名が重複するのを防ぐため

#### スキルの並び替え

- 各スキルに「↑」「↓」ボタンで順序を変更可能
- 基本的にはタイミング順にグループ化されるが、ユーザーが自由に並び替え可能

#### ダブルクリックによるスキルの開閉

- エネミー編集画面のスキルヘッダー部分をダブルクリックすることで、スキルの詳細を開閉できる
- ダブルクリックイベント（`dblclick`）を使用
- スキルヘッダーに`cursor: pointer`を設定し、クリック可能であることを視覚的に示す
- 既存の編集ボタンによる開閉機能も維持される
- ボタンをクリックした場合はダブルクリックイベントを無視する
- 実装:
  - `.skill-header`にダブルクリックイベントリスナーを登録
  - `toggleSkillDetails(id)`メソッドを呼び出してスキルの詳細を開閉
